# Bootstrap Shop

## Контрольная работа №2

Тема: «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

## Описание

Проект представляет собой учебную версию сайта интернет-магазина или каталога товаров, разработанную с использованием Bootstrap.

## Используемый CSS-фреймворк

Bootstrap.

## Способ подключения Bootstrap

Bootstrap подключён через CDN версии 5.3.8. Файл `css/custom.css` подключён после Bootstrap.

## Реализованные Bootstrap-компоненты

- `navbar`;
- `card`;
- `btn`;
- `badge`;
- `alert`;
- `modal`;
- `form-control`;
- `form-select`;
- `input-group`;
- `form-check`;
- `accordion`.
